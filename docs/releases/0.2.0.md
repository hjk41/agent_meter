# Agent Meter 0.2.0

Windows x64 与 Apple Silicon 两个版本，无需额外安装 Python。

## 下载与运行

- **Windows x64**：下载 `AgentMeter-0.2.0-windows-x64.zip`，解压后运行 `AgentMeter.exe`。
- **Apple Silicon**：下载 `AgentMeter-0.2.0-macos-arm64.zip`，解压后将 `Agent Meter.app` 放到应用目录，再打开。需要 macOS 13 或更新版本；不包含 Intel Mac 版本。
- `SHA256SUMS.txt` 提供两个下载包的校验值。包内附使用说明、第三方许可文件与构建版本信息。

## 本版功能

- Windows / macOS 原生半透明额度悬浮窗；Mac 使用菜单栏入口。
- Codex / Cursor 复用本机登录；显示账号实际返回的多个额度窗口。
- 可配置显示的 Agent、排序、主题、代理、登录启动及低额度提醒。
- 双行迷你信息签：名称在上、额度在下；左端窄拖柄、右端紧凑双按钮组；紧凑的标签/数值分组；刷新保持布局稳定。
- 迷你条文字、额度、空白与按钮均可拖动；普通点击保留原功能，拖动不会误触详情或设置。
- 检测旧数据后补刷一次，连续失败等待下一轮定时刷新。

## 使用说明

Codex 额度需要本机官方 CLI 或桌面版组件，Cursor 需要本机已登录的 Cursor。下载包不附带账号信息；首次使用请在原工具完成登录，并检查代理设置。

Mac 包当前使用临时签名，尚未经过 Apple Developer ID 签名与公证。下载后系统可能要求在“系统设置 → 隐私与安全性”确认打开，请先确认文件来自本仓库。

Codex / Cursor 的真实额度已在两平台验证；Claude OAuth 与 macOS 豆包的真实账号额度仍待验证。相关接口可能随原客户端更新而变化。
